# SecureChat v2 (Java + HTML)
Run (Java 17+):
    javac ChatServer.java
    java ChatServer
Open http://localhost:8080 in two tabs, same name-less room key in both. (Use localhost/HTTPS: browser encryption needs a secure context.)
Files: ChatServer.java (relay server), index.html (client). server_log.txt shows the server only sees ciphertext.
